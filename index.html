A LLM architecture
inspired by digital signal processing

Expressive recurrent memory without pole-geometry bias. MIRA draws on signal processing to model token sequences with input-conditioned lattice–ladder dynamics and a dedicated CUDA implementation.

01 / Introduction

A language model with
lattice memory.

A token enters a cascade of coupled forward signals and backward memory states. Input-conditioned rotations and radii control how information propagates; a selective ladder readout gathers information across the stages.

Ut(k−1) = rt(k) ⊙ (cos θt(k) ⊙ Ut(k) − sin θt(k) ⊙ Vt−1(k−1))
Vt(k) = rt(k) ⊙ (sin θt(k) ⊙ Ut(k) + cos θt(k) ⊙ Vt−1(k−1))

The lattice order K, expanded channel width de and per-channel memory dm define a recurrent state whose size stays fixed as the sequence grows.
