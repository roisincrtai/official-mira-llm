#
#     ./old_scripts/stage5_compile_cuda_kernel.sh          # or: make -C kernel/cuda universal check
#
# which produces build/kernel/cuda/{mira_scan,mira_decay,mira_causal_cov1d}.cubin, found through

# at run time. See kernel/cuda/howto.txt. model/mira.py imports no third-party kernel at all;
# its only fallback is pairwise_scan, which is ours and is the reference the cubins are checked
# against.
